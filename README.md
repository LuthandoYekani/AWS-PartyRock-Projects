# 🤖 AWS PartyRock Projects

Welcome to my AWS PartyRock portfolio.

This repository showcases projects and case studies developed using **AWS PartyRock**, Amazon's no-code generative AI platform. These projects demonstrate practical applications of generative AI, prompt engineering, and AI-assisted data analysis.

---

## 📖 Overview

This repository contains two complementary projects:

### 🛡️ CyberGuardian AI Pro

An AI-powered cybersecurity assistant designed to support security awareness, risk identification, and incident guidance through natural language interactions.

### 📊 AI Data Analysis Case Study

A practical case study demonstrating how AWS PartyRock can be used to analyze structured datasets, identify trends, summarize findings, and generate actionable insights using generative AI.
