# 📊 AI Data Analysis Case Study

## Overview

This case study demonstrates how AWS PartyRock can be used to analyse structured datasets using generative AI.

Instead of writing code, PartyRock was used to explore a real-world air quality dataset, identify trends, generate summaries, and produce actionable insights through natural language prompts.

---

## Objectives

- Explore AI-assisted data analysis
- Analyse a real-world dataset
- Identify trends and anomalies
- Generate meaningful summaries
- Evaluate the strengths of generative AI for data exploration

---

## Dataset

The analysis uses an air quality dataset provided as part of an AWS PartyRock learning exercise.

The original dataset and AI-generated outputs are included in this repository.

- Data Exploration
- Prompt Engineering
- AI-assisted Data Analysis
- Insight Generation
- Technical Documentation

## Key Takeaways

This project demonstrates that generative AI can accelerate exploratory data analysis by summarising large datasets, identifying patterns, and producing understandable insights without requiring extensive programming.
